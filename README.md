# Meu Portfólio Pessoal
Este é o repositório do meu portfólio pessoal. Um espaço dedicado para centralizar meus projetos, experiências, habilidades e formas de contato. O objetivo é apresentar minha jornada como desenvolvedor de forma visual e interativa.

## Screenshots
Aqui estão algumas prévias do design e da interface do portfólio:

## Funcionalidades
Design Responsivo: Otimizado para visualização em desktops, tablets e smartphones.

Galeria Dinâmica: Filtros por categorias de projetos (Frontend, Backend, etc.).

Formulário de Contato: Integração para envio de mensagens direto para o meu e-mail.

Link para Currículo: Botão de download direto do meu CV atualizado.

## Tecnologias e Ferramentas
No desenvolvimento deste projeto, utilizei:

Linguagens: HTML5, CSS3, PHP, JavaScript (ES6+).

Frameworks/Bibliotecas: Boostrap 5.

Hospedagem: InfinityFree
